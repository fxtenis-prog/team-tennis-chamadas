Compartilhar e proteger os dados

O backup guarda o histórico e a lista dos alunos. O arquivo contém dados particulares: não o publique no GitHub. Faça um backup regularmente e envie ao responsável. Dados armazenados apenas neste aparelho. Não apague os dados do navegador sem salvar um backup.

Como funciona

Escolha data, dia e turma. Marque P/F/R, ou cancele a turma por chuva com um botão. Uma aula cancelada por chuva gera 1 crédito para cada aluno cadastrado naquela turma no momento do cancelamento. A lista fica congelada no histórico, mesmo se o aluno mudar de turma. Uma presença marcada R desconta um crédito do aluno. Você pode consultar o saldo e exportar um backup. Se selecionar outra turma ou data, o histórico é mantido.

Este app permite instalação e abertura offline após acessar a página publicada com internet. Não há sincronização automática entre celulares. Exporte backups regularmente.
